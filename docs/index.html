Data engineering portfolio project

From messy orders to numbers you can trust.

Raw e-commerce order files go through a Bronze, Silver and Gold pipeline built with PySpark and Delta Lake. Bad records are kept and explained, not silently dropped.

What is live on this page: the charts, the view switcher and the tables. What is not live: the pipeline. It ran locally on PySpark + Delta Lake (not Databricks) with generated data, and this page shows its saved results.
